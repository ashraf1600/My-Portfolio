## Design Tokens Quick Reference

- **Primary Font**: `Poppins` (Bold/Black headings)
- **Technical Font**: `Roboto Mono` (Code comment navigation, tags, dates)
- **Base Background**: `#0f1016` / `#13141b`
- **Brand Cyan**: `#66d9ed`
- **Chonky Underlines**: Magenta `#DF058D`, Blue `#2C49D8`, Amber `#FF6B2B`, Violet `#9440e8`
